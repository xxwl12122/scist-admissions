## 架构与工程化目录 (Architecture)

本项目贯彻高内聚、低耦合的前端模块化设计规范，视图层、表现层、交互层与数据层完全解耦，零复杂构建配置，开箱即用：

```
scist-admissions/
├── 📄 index.html              # 核心视图层：HTML5 语义化骨架、多模态弹窗容器与无障碍结构
├── 🎨 css/
│   └── styles.css             # 表现层系统：Glassmorphism 玻璃拟态、微光动效、自定义滚动条、卡片按钮
├── 🧠 js/
│   ├── data.js                # 数据源仓库：解耦的历年招生大数据、六大拔尖专业库、新闻快讯与 FAQ 知识图谱
│   ├── canvas.js              # 视觉引擎：基于物理动力学的 Canvas 2D 自适应粒子互动网格
│   ├── bot.js                 # 智能交互层：AI 语义诊断路由器、高考估分测算引擎与富文本卡片生成器
│   └── main.js                # 调度控制器：Ctrl+K 搜索指挥台、滚动进度条、灯箱双向翻页、数据表联动
├── 🛡️ .gitignore              # 工程配置文件：过滤系统缓存与调试临时日志
├── 📜 LICENSE                 # MIT 开源授权协议
└── 📖 README.md               # 项目说明文档
```

## 核心通信流图 (Data & Event Flow)

```mermaid
flowchart TD
    User([👤 考生 / 家长]) -->|浏览或检索| View[🖥️ index.html 视图呈现]
    User -->|按键 Ctrl+K| Search[🔍 Search Modal 搜索指挥台]
    User -->|输入分数如: 北京 688| Bot[🤖 AI 智能报考助手]
    User -->|选择生源地/选考科目| Filter[📊 分数线筛选联动引擎]

    subgraph DataLayer [📦 数据持久与解耦层]
        DataJS[(js/data.js 招生大数据)]
    end

    subgraph LogicLayer [⚙️ 核心交互引擎]
        Search -->|模糊索引检索| DataJS
        Bot -->|高考分冲稳保算法测算| DataJS
        Filter -->|多维属性联合过滤| DataJS
        CanvasEngine[🪐 js/canvas.js 粒子引力系统] -->|绘制渲染| View
    end

    LogicLayer -->|动态渲染结构| DOM[✨ DOM 视图树平滑更新]
    DOM --> Toast[🔔 全局 Toast 提示通知]
```

## 本地运行 (Quick Start)

项目采用原生现代前端栈开发，无需安装任何构建工具，直接启动静态服务或双击运行：

```bash
# 1. 克隆仓库
git clone https://github.com/xxwl12122/scist-admissions.git
cd scist-admissions

# 2. 启动本地服务（任选其一）
npx serve .
# 或
python -m http.server 8000
```
